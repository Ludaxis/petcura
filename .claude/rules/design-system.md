# Design System Rules

- Use PetCura tokens and shadcn/ui primitives before custom styling.
- Avoid one-off component variants when a shared variant belongs in `packages/ui`.
- Clinic UI should feel calm, dense, and operational.
- Owner UI should feel simple, direct, and reassuring.
- Keep cards modest and functional; do not nest cards inside cards.
