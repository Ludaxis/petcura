# Accessibility Rules

- All interactive controls need accessible names.
- Icon-only buttons need labels or tooltips.
- Keyboard focus order must match visual order.
- Do not remove visible focus styles.
- Forms need explicit labels, validation messages, and error recovery.
- Check EN/ET/RU text expansion before considering UI complete.
