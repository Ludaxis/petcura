# Web App Rules

- Use Next.js App Router and TypeScript strict mode.
- Prefer server components unless interactivity requires client components.
- Use shadcn/ui primitives and PetCura design tokens.
- Do not introduce new UI libraries without Codex approval.
- Verify all important views at mobile and desktop widths.
- Keep clinic screens dense, calm, and operational.
- Keep owner screens simple, reassuring, and low-friction.
- UI changes must include keyboard, focus, contrast, and text expansion checks.
